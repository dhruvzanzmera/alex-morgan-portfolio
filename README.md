# Alex Morgan Portfolio

A single-page frontend portfolio built with HTML, Tailwind CSS, and vanilla JavaScript.

## Overview

This project is a personal portfolio landing page for a frontend developer named Alex Morgan. It includes:

- Hero section with animated intro and call-to-action links
- About section with experience highlights
- Skills section with technology categories
- Projects section showcasing selected work
- Contact section with a mailto-based form
- Dark-mode toggle and mobile navigation
- Smooth scroll and responsive layout

## Built With

- HTML5
- Tailwind CSS (via CDN)
- JavaScript
- AOS (Animate On Scroll)

## Features

- Responsive design for desktop and mobile
- Dark/light theme toggle
- Animated scroll reveal using AOS
- Contact form opens the default email client via `mailto:`
- No build step required

## Usage

1. Open `index.html` in your browser.
2. Or, use a local development server such as VS Code Live Server for the best experience.

## Notes

- The page uses external CDN resources for Tailwind CSS and AOS.
- The contact form does not submit to a backend; it creates an email draft instead.
- Theme preference is toggled in-memory only and does not persist across reloads.
